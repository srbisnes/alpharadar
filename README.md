# AlphaRadar

**Discover Alpha. Trade Smarter.**

Non-custodial discovery for tokenized stocks on BNB Chain (bStocks · Ondo · xStocks).

Built for **BNB Hack: Tokenized Stocks Edition**.

## Features

- **Radar feed** — Alpha Score, Premium Gap vs reference, Why Now
- **Charts** — Price + VWAP + reference line (live tick)
- **Footprint** — Buy/sell volume profile simulation
- **Heatmap** — Premium gap intensity grid
- **Alpha Agent** — Chat assistant with live radar data
- **Wallet** — MetaMask / Binance Wallet, BSC switch
- **Registration** — Local profile (non-custodial)
- **Favorites** — Saved in localStorage

## Quick Start

```bash
npm install
npm run dev
```
